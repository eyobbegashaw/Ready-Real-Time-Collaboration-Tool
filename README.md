###﻿# EthioChat - Real-Time Collaboration Tool

A modern, feature-rich chat application designed specifically for Ethiopian users, with real-time messaging, group chats, file sharing, and voice notes.

## 🌟 Features

### Core Features
- **Real-Time Messaging**: Instant message delivery with read receipts and typing indicators
- **Group Chats**: Create groups for teams, friends, families, Iddir, and Equb
- **Media Sharing**: Send images, documents, and voice notes
- **Message Reactions**: React with emojis including Ethiopian cultural emojis
- **Message Search**: Search through chat history by keyword, sender, or date
- **Push Notifications**: Mobile and web push notifications for new messages
- **End-to-End Encryption**: Optional encryption for private conversations
- **Voice/Video Calls**: WebRTC-based voice and video calls

### Ethiopian Context
- 🇪🇹 Cultural emojis (Buna, Injera, Meskel, etc.)
- 📱 Low-bandwidth mode for data saving
- 🎤 Voice notes for users with lower literacy
- 👥 Community-focused features (Iddir, Equb groups)
- 🌐 Full Amharic language support with proper RTL

### User Experience
- 📱 Responsive design for mobile and desktop
- 🌓 Dark/Light mode toggle
- 🔔 Customizable notifications
- 💾 Auto-download media toggle for data saving
- 🔄 Message forwarding and reply threading
